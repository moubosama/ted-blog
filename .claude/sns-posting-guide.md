# SNS投稿ガイド

## 対象プラットフォーム（この4つを必ず作成）

1. **X（Twitter）**
2. **Pinterest**
3. **Threads**
4. **note**

---

## 共通ルール

### 1. 「負」の状況から入る
- 冒頭は共感を呼ぶネガティブな状況から始める
- 「最悪の日」「失敗した」「困っていた」など

### 2. 書き手の「体温」を入れる
- 必ず1箇所は自分の感想・体験を入れる
- 「この考え方を知ってから〜」「自分も〜するようになった」
- AIっぽい無機質な要約にならないように

### 3. 「引き」を作る（ブログを読む理由）
- 記事内で結論を完結させない
- 「〜の対処法」「〜の例え話が深かった」など、ブログにしかない情報への期待感を作る
- 「続きはこちら」の前に、何が書いてあるか具体的に示す

### 4. リンクの置き方
- 最後に1つだけ
- 「続きはこちら👇」の後に置く

---

## プラットフォーム別

### X（Twitter）
- 280文字制限を意識
- 改行多め
- インパクトある冒頭
- ハッシュタグは不要（または1-2個）

### Threads
- 日記的・情緒的な文章が好まれる
- 改行スカスカでOK（スマホで読みやすく）
- 自分の感想を最後に1行入れる
- ハッシュタグは3-4個
- 画像をつけるとインプレッション数倍

### Pinterest
- タイトルは具体的に
- 説明は100-150文字程度
- ハッシュタグは5-6個
- SEOを意識したキーワードを入れる

### note（エッセイ型）★重要★

**noteで読まれる記事の特徴（2026年分析）**
- 体験ベースの語り：「〜してみた」「〜に気づいた」
- 一人称の悩み・気づきが主役、TEDは「きっかけ」程度
- 具体的な数字やエピソードが多い
- 等身大の視点（完璧なノウハウより「悩んでた自分」）

**構成テンプレート**
1. 自分の思い込み・前提から入る（「正直、〜だと思ってた」）
2. それが揺らいだきっかけ（TED）
3. 具体的な内容（研究データ、エピソード）
4. 自分への適用・気づき
5. ブログへの誘導（具体的な内容の予告付き）

**タイトルの傾向**
- 数字を使う（奇数が効果的：3、5、7）
- 具体的なベネフィット（「〜できるようになる」）
- 好奇心を刺激（「意外な」「誰も教えてくれない」）
- ❌「冤罪を生む記憶テストのタイミング」（説明型）
- ✅「目撃証言を信じてた自分が、ゾッとした理由」（体験型）

**冒頭の例**
- ❌「DNA鑑定で冤罪が次々と発覚。」（客観的説明）
- ✅「正直、目撃証言ってかなり信じてた。」（一人称の前提）

**長さ**
- 短すぎNG（何の研究か分からない）
- 研究の詳細（誰が、どこで、何人、何年）を入れる
- 最低でも800文字以上

**その他**
- ハッシュタグは6-8個
- リンクは改行してカード表示させる
- 「---」で区切りを入れて読みやすく

---

## やってはいけないこと

1. **解説だけで終わる**: TEDの内容をそのまま要約しただけ → 書き手の視点がない
2. **自分語りしすぎる**: 「俺も〜」「すげー」連発 → キモい
3. **結論を全部書く**: ブログを見る理由がなくなる
4. **リンクだけ貼る**: 何が書いてあるかわからない

## 良い例

### 冒頭
❌ 「このTEDでは〜について語られています」
✅ 「人生最悪の日って、何も考えたくなくなる」

### 自分の体温
❌ （なし）
✅ 「この考え方を知ってから、最悪な帰り道も少しだけ短く感じるようになりました」

### リンク誘導
❌ 「詳しくはブログで👇」
✅ 「『嫌いな相手への対処法』や『電球の例え話』が深かったのでブログにまとめました。続きはこちら👇」
