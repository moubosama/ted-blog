## TED要約ラボとは

TED要約ラボは、世界中の優れたTEDトークを日本のビジネスパーソン向けに翻訳・要約するメディアである。

AIを活用して新着TEDトークを要約・公開し、各トークから**ビジネスに転用できる教訓**を抽出している。

## 特徴

- **ビジネス視点**: 単なる翻訳ではなく、日本のビジネス文脈に合わせた翻案
- **AI要約**: Claude Codeを活用した高品質な日本語記事生成
- **3つの教訓**: 各記事の末尾に、すぐに実践できるビジネスへの教訓を掲載

## 技術スタック

- 静的サイトジェネレーター: Hugo + PaperMod
- AI翻訳・要約: Claude Code (Anthropic)
- ホスティング: GitHub Pages

本サイトの記事はAIによる自動生成であり、原著者の意図と異なる解釈を含む可能性がある。正確な内容については、各記事に記載されたTEDトークの原典を参照されたい。
